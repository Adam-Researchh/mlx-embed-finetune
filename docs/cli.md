# Command line reference

Run commands from the repository root in the environment described in the
[README](../README.md#quick-start). `--help` prints the installed command
interface. The [training guide](training.md) and [evaluation guide](evaluation.md)
explain which settings must be used together.

`unset` means no value is supplied by default; `off` means a boolean flag is
disabled. Training paths must be fresh run directories, and generated score/report
paths must be new files. Benchmark utilities also require new output paths.


## Training

Source: [train.py](../train.py).

```bash
python train.py --help
```

| Flag | Default | Meaning |
|---|---|---|
| `--train-pairs` | required | JSONL file with training pairs |
| `--eval-pairs` | unset | Optional held-out validation pairs |
| `--eval-corpus` | unset | Additional validation corpus JSONL (id/text) |
| `--best-metric` | loss | Metric used to select the best checkpoint. Choices: loss, ndcg_at_10, mrr_at_10, recall_at_10. |
| `--save-every` | 100 | Save adapters every N steps; 0 disables periodic saves |
| `--hardness-strength` | 0.0 | Detached cosine penalty on negatives; 0 disables weighting |
| `--model` | mlx-community/bge-m3-mlx-fp16 | Model path or repository (default: mlx-community/bge-m3-mlx-fp16) |
| `--epochs` | 3 | Number of training epochs |
| `--batch-size` | 16 | Queries per contrastive loss; with GradCache this can exceed the encoding chunk size |
| `--grad-accum-steps` | 1 | Accumulate gradients over N micro-batches before an optimizer step |
| `--multi-positive` | off | Train uniformly on all known positives and deduplicate candidates |
| `--cache-chunk-size` | 0 | Enable GradCache, encoding at most N texts at once; batch-size is the logical contrastive batch |
| `--loss-chunk-size` | 64 | Queries per embedding-loss gradient chunk in GradCache mode |
| `--cache-forward-mode` | plain | Cache pass: `plain` or experimental `autodiff`, which follows the differentiated forward path without promoting model precision. Requires caching for `autodiff`. |
| `--teacher-scores` | unset | Offline teacher ranking JSONL generated by teacher.py |
| `--distill-weight` | 0.0 | Add this weight times teacher-to-student ranking KL to contrastive loss |
| `--distill-temperature` | 0.1 | Temperature applied to both teacher and student distillation scores |
| `--learning-rate` | 2e-05 | Peak learning rate |
| `--weight-decay` | 0.01 | Weight decay |
| `--temperature` | 0.05 | Contrastive loss temperature |
| `--max-length` | 512 | Maximum token length |
| `--lora-rank` | 8 | LoRA rank |
| `--lora-alpha` | 16.0 | LoRA alpha |
| `--lora-dropout` | 0.0 | LoRA dropout |
| `--target-modules` | auto | Which linear modules to adapt: 'auto' (detect the architecture), 'all-linear' (every linear inside a transformer block), a comma-separated list of module names (e.g. query,value), or regexes matched against module paths (e.g. 'attn\.(Wqkv\|Wo)$') |
| `--query-prefix` | empty string | Prefix prepended to every query, e.g. 'search_query: '. Use the selected checkpoint's prompt recipe; requirements vary between models. |
| `--doc-prefix` | empty string | Prefix prepended to every positive/negative document, e.g. 'search_document: ' |
| `--no-hard-negatives` | off | Ignore the `negatives` field and use in-batch negatives only |
| `--no-normalize` | off | Skip explicit L2 normalization of embeddings (not recommended) |
| `--matryoshka-dims` | unset | Comma-separated nested dims for Matryoshka loss, e.g. 768,512,256,128,64 |
| `--merge` | best | Which adapter weights to fuse into the exported model (default: best). Choices: best, final. |
| `--keep-checkpoints` | 3 | Number of numbered checkpoints to retain (0 = keep all) |
| `--output-dir` | outputs/mlx-embed-finetune | Output directory |
| `--log-every` | 10 | Log every N optimizer steps |
| `--eval-every` | 100 | Evaluate every N optimizer steps; 0 disables eval |
| `--seed` | unset | Random seed for shuffling and MLX |
| `--dry-run` | off | Load model and process one batch for speed estimates |

## Important combinations

- `--batch-size` sets a shared contrastive pool; `--grad-accum-steps` combines
  separate losses before an optimizer update. `--cache-chunk-size` bounds each
  encoding/replay chunk. `--loss-chunk-size` bounds cached loss-gradient chunks
  and validation loss chunks; it does not chunk an ordinary uncached training graph.
- Distillation requires both `--teacher-scores` and a positive `--distill-weight`.
  It cannot be combined with `--no-normalize` or `--no-hard-negatives`.
- `--cache-forward-mode autodiff` requires a positive `--cache-chunk-size`.
  It changes the cache forward computation without changing the objective.
- Retrieval-based `--best-metric` requires `--eval-pairs` and enabled evaluation.
  `--eval-every 0` disables both periodic and final evaluation.
- Matryoshka dimensions must be distinct positive integers within the model's
  output size. Evaluation dimensions must also fit; full dimension is always included.
- The mining rank range is applied before known-positive and margin filtering.
  Shortfalls are reported without relaxing the filters.

See [troubleshooting](troubleshooting.md) for errors and
[design rationale](design-rationale.md) for the objective definitions.
